# 🛒 ElectroStore - Electronics E-Commerce Website

A simple and responsive Electronics E-Commerce Website built using **HTML5, CSS3, and JavaScript**. This project demonstrates the fundamentals of front-end web development by creating a multi-page online electronics store.

---

## 📌 Features

- 🏠 Home Page with Hero Section
- 📱 Products Page displaying electronic items
- ℹ️ About Page
- 📞 Contact Page with Contact Form
- 🎨 Responsive Design
- 🛍️ Add to Cart Button (JavaScript)
- 💻 Clean and Beginner-Friendly UI
- 📱 Mobile Responsive Layout
- 🌐 Easy Navigation Between Pages

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/electrostore.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code**.

### 3. Run the Website

Open `home.html` (or `index.html` if renamed) in your web browser.

Or use the **Live Server** extension in VS Code.
